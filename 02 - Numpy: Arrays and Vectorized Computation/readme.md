## 📌 About This Repository

This repository contains my hands-on learning journey through NumPy,
a fundamental Python library for numerical computing and array-based
data manipulation.

The objective is to understand NumPy concepts through practical
implementations, concise notes, code examples, and experimentation.

The documentation focuses on explaining important concepts in my
own words rather than reproducing lengthy textbook explanations.

## 🎯 Learning Objectives

- Understand NumPy arrays and their properties.
- Learn array creation, indexing, and slicing.
- Explore array data types, shapes, and reshaping.
- Understand the difference between copies and views.
- Perform array iteration, joining, and splitting.
- Search, sort, and filter array elements.
- Generate random numbers and explore probability distributions.
- Understand and implement NumPy universal functions (ufuncs).
- Perform numerical operations efficiently using NumPy.
